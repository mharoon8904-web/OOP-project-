# Module 11: Cottage Manor Location Manager

##  Module Overview
Implements Cottage managing an aggregated DynamicArray<Location> containing 7 manor locations. Loads location titles from file or defaults, attaches hidden letter clues, and tracks search status.

##Key OOP & Architectural Concepts Demonstrated
- **Aggregation, File I/O, DynamicArray Storage, Pointer Iteration, State Tracking.**
