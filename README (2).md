# Module 10: Jagged Scrabble Board

##  Module Overview
Implements Scrabble board using a 2D jagged DynamicArray<DynamicArray<Tile>> (Row 1: 7 slots, Row 2: 8 slots). Implements word cipher matching, tile placement, out-of-bounds protection, and stream operators.

##  Key OOP & Architectural Concepts Demonstrated
- **Jagged Dynamic Arrays, Nested DynamicArray Templates, Exception Throwing (InvalidPositionException), Cipher Verification, Stream Operators.**
