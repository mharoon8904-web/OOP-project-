# Module 09: TileRack Evidence Manager

##  Module Overview
Implements TileRack refactored with DynamicArray<Tile>. Manages maximum 15 evidence letter tiles, throws RackFullException, overloads operator+ to combine racks, and provides pointer arithmetic iterators.

##  Key OOP & Architectural Concepts Demonstrated
- **Composition, Operator Overloading (+), Exception Throwing, Pointer Iteration, Encapsulation.**
