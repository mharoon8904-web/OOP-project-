# Module 12: GameEngine Singleton, Game Loop & Master Driver

## 📌 Module Overview
Completes the application orchestrating all OOP relationships (Composition of Detective, Victim, Cottage, Scrabble, TileRack, Suspects; Association with persistent files; Aggregation of Locations). Implements full game loop, UI, turn/credibility economy, and robust main() driver with top-level exception catching.

## 🧠 Key OOP & Architectural Concepts Demonstrated
- **Singleton Pattern, Composition, Aggregation, Association, State Machine, Top-Level Exception Handling, File Persistence.**
